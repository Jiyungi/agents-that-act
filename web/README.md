# `web/` — Frontend_UI (Person B)

Next.js (App Router) + React + TypeScript + Tailwind frontend served from the
same Vercel deployment as `api/`. Implements the search/scan flow, the manual
handoff panel, the verdict card, and the gallery.

See `.kiro/specs/packguard/frontend-design-prompt.md` for the full UI spec.
The frontend itself is built in Person B tasks (14, 15); this directory is
scaffolded here so the repo layout and tooling are in place.
