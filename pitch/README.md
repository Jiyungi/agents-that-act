# PackGuard — Pitch Deck

A self-contained, single-file slide deck for the Applied Intelligence Hackathon
("Agents That Act") pitch. No build step, no dependencies — just open it.

## Run it

```bash
open pitch/index.html        # macOS
# or just double-click the file
```

## Controls

- `→` / `Space` — next slide
- `←` — previous slide
- `F` — toggle fullscreen (use this when presenting)
- click the progress dots to jump
- swipe left/right on touch devices

## Slides (9)

1. **Title** — PackGuard + tracks/sponsors
2. **Problem** — installing runs code before you read it
3. **Solution** — type a name, get a verdict, never install
4. **How it works** — the automated→manual→automated agent flow
5. **Why it's safe** — hardened extraction + property-based tests
6. **The output** — the SAFE/RISKY verdict card with honest framing
7. **The stack** — Opsera, Tigris, Daytona, Vercel + architecture
8. **Impact & next** — demo today → sandboxed → CI/IDE guardrail
9. **Closing** — "Read before you run."

Styling mirrors the product's terminal/hacker theme (`web/src/styles.css`) so the
deck and the app feel like one thing.
